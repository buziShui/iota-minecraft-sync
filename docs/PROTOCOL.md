# iota-sync/1 协议

清单包含实例 ID、实例名、发布 ID、Minecraft/加载器版本、直连服务器地址及文件数组。每个文件包含相对路径、字节数、SHA-256 和端侧：

- `0`：客户端必需。
- `1`：客户端可选，首次默认安装。
- `2`：仅服务端，不进入发布快照。
- `3`：待人工确认，存在时拒绝发布。

客户端把已安装受管文件写入实例根目录的 `.iota-sync-state.json`。更新删除只针对该文件记录且内容仍匹配旧 SHA-256 的文件；未知文件永不自动删除。被玩家修改的受管文件会触发冲突选择。

更新前文件备份到实例根目录 `.iota-backup/时间/`。下载先写入 `.iota-downloading`，SHA-256 通过后才替换目标文件。
