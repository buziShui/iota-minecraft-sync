# Iota Minecraft 同步系统

本仓库包含两个独立项目：

- `mslx-plugin-iota-sync`：适配 MSLX 1.4.7 的 Linux 服务端同步插件。
- `pcl-io`：Windows 10/11 x64 客户端 `Plain Craft Launcher (PCL) IO`。

项目开发者署名为 BuZiShui。PCL IO 是第三方二次创作，与 PCL 官方无关；原作者与赞助入口保留在客户端关于页面和子项目说明中。

## 状态

当前为开发版协议 `iota-sync/1`。正式对朋友分发前，应补充公开源码仓库地址，并使用 HTTPS 或明确接受 HTTP 下同步码可能被旁路读取的风险。
